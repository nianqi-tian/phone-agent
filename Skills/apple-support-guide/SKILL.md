# 苹果官方帮助

把用户的目标转成适合其设备的操作说明，或在已有操控能力内执行并检查结果。知识来源是 Apple 当前官方文档；本 skill 提供全产品范围的入口、检索与操作规则，**不是苹果所有文档全文的离线副本**。不把入口核对日期当作各篇文档的更新日期。

## 找到适用的说明

1. 从对话和可见设备信息确定产品、系统或 App 版本、界面语言，以及影响该功能的地区。不要把模拟器当作用户的实体设备，也不要把某次任务的机型、设置和配件推广到全部任务。
2. Apple 文档问题先读 [官方来源索引](references/official-sources.md) 中对应类别。一般使用方法查产品手册；异常、错误码和维修问题查支持文章；组织管理查部署手册；开发和上架查开发者帮助。日常 iPhone 操控任务依据手机操作索引和当前截图，不需要把其他产品目录混入无关任务。
3. 打开与问题直接相关的官方正文，核对标题、适用设备、版本选择器、功能前提及地区限制。搜索摘要只用于找文章，不能替代对关键步骤的正文核对。
4. 手册有版本选项时选择用户实际版本，沿页面链接进入具体主题。不要猜文章 ID，不要给 URL 随意拼接系统版本。最新版指南和旧设备不一致时，优先匹配版本；没有对应版本就明确说明差异。
5. 使用当前可用的网页工具检索；有文档读取工具或用户提供的官方 PDF 时可先读它们。首选简体中文，缺少适用内容时读取英文，并保留原始控件名帮助核对。

检索示例：

```text
site:support.apple.com/zh-cn/guide/iphone 聚焦搜索
site:support.apple.com/zh-cn 蓝牙 鼠标 辅助触控
site:support.apple.com/zh-cn Mac 无法连接 Wi-Fi
site:support.apple.com Pages iPad 导出 PDF
site:developer.apple.com/help/app-store-connect TestFlight
```

没有结果时去掉版本词、改用英文功能名、进入产品目录或更换官方文档入口。索引没有某个新品/软件也继续从总目录和官方搜索查找。官方社区、论坛中的用户答复应标明性质，不能称作 Apple 官方操作说明。

## 说明与实际执行

用户只问“怎么操作”时，给出准确菜单路径和需要的前提。用户要求“帮我设置/打开/处理”时，在当前宿主真正具备的能力内继续执行；文档里的手势、按键或功能不等于工具支持它们。

- 先看当前页面，再按目标文字、图标与上下文选择控件；不把官网示意图或另一台手机的坐标用于当前设备。
- 一次完成一个有明确结果的操作，观察新画面后决定下一步。长按、触控滚动、鼠标滚轮和键盘快捷键按实际工具区分。
- 原生手势、物理按键、Fn/地球键或生物识别不可用时，查当前系统支持的可见替代入口。不要宣称工具执行了没有实现的操作。
- 系统页面与手册的名称不同，先检查系统版本、语言和页面位置；可使用设置搜索找功能。没有找到并不证明设备不支持。
- 登录、受管理设备策略、配对、硬件限制和第三方 App 可用性按实际状态判断；不从“存在这篇手册”推断本机已就绪。
- 涉及同步数据、备份、抹掉、恢复、账户和付费事项时，额外阅读 [诊断和数据操作](references/troubleshooting.md)；遵循宿主现有授权规则。阅读文档不会额外授予设备或账户操作权限。

iPhone/iPad 的桌面搜索、辅助触控、指针、键盘、Siri、快捷指令和画中画，按需读 [手机操作索引](references/iphone-operation.md)。本 skill 可独立回答官方使用说明，不要求预装其他 skill。宿主已有手机执行规则时，保留其动作协议与当前能力限制。

## 输出与结果核对

按用户目标给出简短操作步骤，通常先写“在哪个页面做什么”，再补必要前提。引用实际读取的具体文档链接，避免只给首页；将版本/地区例外放在相关步骤旁。

执行后，以当前设置值、目标页面或实际产物核对成功。只导航到了入口就报告已到入口；未观察到结果则说明未确认。诊断把已看到的现象、官方支持的原因和推测区分开。

正文无法访问时换官方语言或目录入口；仍无法读取则说明哪些步骤未核实。离线时可以基于用户提供的文档解释，不能声称已经确认最新设置路径。不要保存用户密码、验证码、恢复密钥或把它们加入检索词。

## 更新

仅在相关链接失效、版本变动或出现新产品时更新索引和局部规则。保留来源 URL 与实际核对日期，补充新的目录入口即可扩展覆盖。不要全站抓取全文并塞进系统提示词，不把版权手册全文作为本 skill 的资产。
